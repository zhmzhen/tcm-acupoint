## 下载技巧

### Wikimedia Commons
1. 访问分类页面或搜索页面
2. 点击图片进入详情页
3. 查看授权信息（确保是 CC 或公有领域）
4. 点击"原始文件"下载高质量版本
5. 或使用"下载"按钮选择合适尺寸

### iNaturalist
1. 搜索物种名称
2. 查看观测记录
3. 点击图片查看详情
4. 检查授权信息
5. 右键保存图片或使用下载链接

### GBIF
1. 搜索物种
2. 进入物种页面
3. 查看"媒体"标签
4. 按许可证过滤
5. 下载图片

## 图片选择标准

1. **清晰度**: 选择高分辨率图片（至少 800x800）
2. **角度**: 选择正面或侧面清晰展示花朵的图片
3. **背景**: 优先选择纯色或模糊背景的图片
4. **授权**: 确保是 CC BY、CC BY-SA 或公有领域
5. **真实性**: 确保是真实照片，不是插画或合成图

## 授权信息记录

建议在下载图片时记录授权信息，格式如下：

```
图片: 玫瑰_Rose_01.jpg
来源: Wikimedia Commons
作者: [作者名]
授权: CC BY-SA 4.0
链接: [原始链接]
```
